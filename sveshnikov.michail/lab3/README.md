# Лабораторная работа 3

## Задание

Вариант 38

Реализуйте функцию sortByFrequency(arr), которая сортирует
элементы массива по частоте встречаемости.

| Функция           | Описание                                                            |
| ----------------- | ------------------------------------------------------------------- |
| `sortByFrequency` | Частые элементы идут первыми; случаи равной частоты не проверяются. |

## Реализация

Опишите экспортируемую функцию, алгоритм и граничные случаи.

## Запуск

Импортируйте именованный export из `solution.js` как ES module.
